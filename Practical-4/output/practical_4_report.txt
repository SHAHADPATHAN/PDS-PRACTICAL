Attack Detection Rules:
SQL Injection: OR 1=1, UNION SELECT, SELECT FROM, INSERT INTO, DELETE FROM, DROP TABLE.
Path Traversal: ../, ..\, %2e%2e, /etc/passwd.
Brute Force: Five or more authentication-related records from the same IP.

Dataset Limitation:
The supplied cj.log dataset does not contain explicit URL, HTTP method, or status-code fields. Therefore, classification is based only on patterns available in the dataset.
